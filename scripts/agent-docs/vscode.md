## The VS Code extension

The craftos-mcp extension (`Rogiedoji.craftos-mcp` on the Visual Studio Marketplace, also on Open VSX as
`Rogiedoji/craftos-mcp`) gives Copilot's agent mode the MCP server with no config, adds Run in CraftOS and Debug in
CraftOS (F5) for any `.lua` file, lists `*.test.lua` files in the Testing view, opens `*.world.json` files in a world
editor, and in Cursor and Windsurf offers to write their MCP config. Its command **Add Agent Instructions to
Workspace** writes these instructions for Codex, Copilot, Cursor, Gemini CLI and Claude Code into the open folder.
