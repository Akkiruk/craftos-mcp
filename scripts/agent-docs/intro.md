craftos-mcp is a headless CC:Tweaked (ComputerCraft) emulator with an MCP server: the `craftos_*` tools run Lua
programs on emulated computers, read the terminal and every monitor as text, tap buttons, change the world around the
computer and run tests. Run and test every ComputerCraft program in it before saying it works, and before it goes on
a computer in a real game.
